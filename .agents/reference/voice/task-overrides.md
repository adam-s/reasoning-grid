# Task Overrides

## Explanatory mode

- Expand context before the central claim.
- Use multi-step reasoning and comparisons.
- Favor clarity over punchiness.

## Argument mode

- Make the thesis clearer earlier.
- Keep contrastive structure visible.
- Reduce side branches that do not strengthen the argument.

## Reflective mode

- Allow more first-person grounding.
- Permit slightly more conversational compression.
- Keep introspection tied to a broader point.

## Instructional mode

- Increase structural explicitness.
- Reduce exploratory wandering.
- Convert analysis into ordered guidance.

## Summary mode

- Keep the analytical tone.
- Compress aggressively, but preserve the reasoning spine.
- Avoid forum-style fragments unless the target format is highly conversational.
