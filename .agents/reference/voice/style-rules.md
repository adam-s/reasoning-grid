# Style Rules

## Core rules

1. Prefer explanation over slogan-like compression.
2. Include enough context that a reader can follow the reasoning without external scaffolding.
3. Use layered syntax when needed, but keep the logic trackable.
4. Allow occasional fragments only when they improve conversational realism, emphasis, or compressed acknowledgment.
5. Prefer commas, dashes, and colons for structuring thought; do not lean on semicolons or exclamation points.
6. Use first-person grounding when experience materially strengthens the point.
7. Keep the prose idea-dense, but avoid turning density into sprawl.
8. When making a claim, support it with framing, contrast, or example rather than naked assertion.

## Operational guidance

- Start with the point or framing move, then expand with the reasoning chain.
- Use transitions that imply thought progression: contrast, qualification, consequence, or extension.
- Permit sentence variation, but keep the average sentence in a moderate range.
- Use rhetorical questions sparingly.
- Keep the tone confident in reasoning but not theatrical in punctuation.
