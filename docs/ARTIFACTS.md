# Published charts

**Every published chart gets an entry here, in the same commit that publishes
it.** An artifact URL that exists only in a chat transcript is lost the moment
the session ends — the page stays live and nobody can find it. An entry needs
the URL, the script that generates it, and one line on what it settles.

Every chart is generated by a committed script from `derived/*.json`, which is
itself generated from `runs/*.jsonl`. Nothing here is hand-drawn, and any of it
can be rebuilt from raw at any time.

Artifacts are **private by default**. Share from the page's own share menu.
Re-running a render script and republishing the same file path updates the same
URL, so these links stay valid as the data grows.

## The pipeline

```text
runs/*.jsonl                 raw, immutable, one record per generation
  -> probe/reduce_grid.py    scores from raw_text, pools by CONDITION
  -> derived/*.json          small, one file per sweep
  -> probe/render_*.py       self-contained HTML, inline SVG, no CDN
```

Rebuild everything:

```sh
python probe/reduce_grid.py --sweep 10-grid12 --pool 11-ext14 --out derived
python probe/render_grid.py         derived/10-grid12.json -o derived/grid.html
python probe/render_blindspots.py   derived/10-grid12.json -o derived/blindspots.html
python probe/render_ladder.py       derived/10-grid12.json -o derived/ladder.html
python probe/render_distribution.py                        -o derived/distribution.html
python probe/render_convergence.py  --cell 7x7             -o derived/convergence.html
```

## The charts

### 1. The surface — reliability by operand size

[Open the chart](https://claude.ai/code/artifact/e4951c5c-52df-4424-9c91-e430e5e94277)

`probe/render_grid.py` &rarr; `derived/grid.html`

x = digits of A, y = digits of B, z = P(exactly correct). A 3D isometric surface
leads, with both models' flat grids beneath it and the paired table below. Uses
the same projection and painter's algorithm as the Rubik's cube renderer in
`agent-capability-threshold` — SVG polygons, no canvas.

**Says:** Qwen3-4B runs from 100% through N=12 down to 3% at 14&times;14, with
nine cells at 0/12. Boundary d\* = 8.56 digits.

### 2. Blind spots — do two models fail in the same places?

[Open the chart](https://claude.ai/code/artifact/4c09cb41-a2e3-4c09-a27c-6258775f04e7)

`probe/render_blindspots.py` &rarr; `derived/blindspots.html`

Diverging map over the 1,062 paired problems. Blue where only Qwen solved what
Phi-4-reasoning missed, orange the reverse, grey where neither ever did. A ring
marks cells where each model rescued the other at least once.

**Says:** Qwen wins outright (McNemar 58.1) **and** Phi-4-reasoning still solves
104 problems Qwen misses — 34% of its failures. Coverage 71.0% &rarr; 80.8%.
51 of 144 cells have rescues in both directions.

**This is the chart the essay's argument rests on.**

### 3. Ladder — pass rate with intervals by size

[Open the chart](https://claude.ai/code/artifact/434ba2a5-8d85-4b16-9be5-c9368cbbf3b1)

`probe/render_ladder.py` &rarr; `derived/ladder.html`

The essay site's own format: dot, Wilson bar, trial count, shaded live band.
Both models overlaid along the diagonal.

**Says:** the transition is steep — three steps carry Qwen from 100% to 0%,
because N grows as d&sup2; along the diagonal. Only 4 of 13 diagonal points sit
in the live band, so most genuinely uncertain cells are off-diagonal.

### 4. Distribution — the grid is a cloud, not a curve

[Open the chart](https://claude.ai/code/artifact/8d710adb-b1a8-4ad2-9862-40cd3469c74b)

`probe/render_distribution.py` &rarr; `derived/distribution.html`

All 196 cells as points against N on a log axis, the fitted boundary through
them, and the band pure coin-flipping would produce at n=12.

**Says:** dispersion &phi; = 1.68 — cells scatter ~68% wider than chance, so
N = a&times;b is a good predictor of difficulty but not a complete one. Only 6%
of cells fall outside their 95% interval against 5% expected, so it is mild
extra variance rather than a few anomalous sizes.

### 5. Convergence — what one cell's number is made of

[Open the chart](https://claude.ai/code/artifact/750a6a84-6f09-41d5-a46c-a302d2a9d3f0)

`probe/render_convergence.py` &rarr; `derived/convergence.html`

Running pass rate for a single cell with the Wilson band narrowing behind it,
and a per-trial strip. Currently Qwen at 7&times;7, 17 pooled trials.

**Says:** no single cell has converged. After 17 trials the interval still spans
38 points, and the running estimate drifted 14 points during the second half.
The boundary is trustworthy because 196 cells agree, not because any one is
precise.

### 6. Operand order — is 3&times;12 the same problem as 12&times;3?

[Open the chart](https://claude.ai/code/artifact/a6c04e02-5538-41b6-aeaa-afef7f5e8754)

`probe/render_order.py` &rarr; `derived/order.html`

168 products, each run once as A&times;B and once as B&times;A, paired on
`instance_uid`. Panel one is the paired 2&times;2 as a proportional bar; panel
two is the disagreement rate by size against a same-order control.

**Says:** no effect, twice over. Neither order wins (McNemar &chi;&sup2;=0.42,
p=0.519), and swapping produces no more disagreement than simply asking twice
(36% vs 28% matched on size, p=0.157). The ~third of products that flip between
attempts are temperature 0.7, not order.

**Also says how nearly it went wrong.** Uncontrolled, swapped ran 36% against
the control's 21% and looked like a strong effect — but the control pairs were
easier problems. The apparent finding was difficulty wearing a costume, and the
control is the entire result.

Requires `--swap true` on the `grid` entrypoint, which reuses existing instances
with the operands reversed in the prompt while keeping `x`/`y` in canonical
order on the record, so the two presentations pair exactly.

### 7. Reasoning on against reasoning off

[Open the chart](https://claude.ai/code/artifact/803dfda8-3491-4960-a6b3-8c7e5debd6b0)

`probe/render_thinking.py` &rarr; `derived/thinking.html`

The same 196 cells run twice — identical model, instances, seeds and
temperature, with only the chat template's thinking flag changed. Two clouds
with their fitted curves and the gap between them shaded.

**Says:** 58.0% against 24.0%; the boundary moves from **8.56 digits to 5.74**.
Through N=30 the two are within a few points, then they part — 82% against 22%
at N=31&ndash;56. Reasoning buys 2.8 digits.

**Careful with the phrasing.** Reasoning-off averages 776 tokens against 14,831,
which is barely enough to write a twelve-digit product let alone derive one. So
this is not "reasoning helps by 34 points" — with reasoning the model computes,
without it it recalls, and recall runs out where a product stops being a fact
and starts being a procedure.

Not available from this data: **temperature 0 against 0.7.** The temp-0 grid run
died in sweep 05, and what remains is at the wrong `top_p` or has thinking
unrecorded. A clean comparison needs a fresh pass.

### 8. The surface settling — animated over trial count

[Open the chart](https://claude.ai/code/artifact/8c8cd53d-dd1e-4325-bed2-1e159cd043db)

`probe/render_animation.py` &rarr; `derived/animation.html`

The 3D surface redrawn at every trial count, with a scrubber and a play control.
Same projection and painter's algorithm as chart 1, moved into inline JS so the
geometry can be rebuilt per frame. 12 KB total — the 1,566 individual outcomes
are embedded as an array; no library, no canvas, no CDN.

**Says:** the shape is roughly right after one trial but reads as a cliff,
because every cell is 0% or 100%. The middle fills in over the next few trials,
and by about eight the terrain stops changing shape and only jitters.

**Also makes the sampling plan visible.** A readout counts how many cells are
still measuring. Saturated corners got three trials and freeze; transition-band
cells got twelve and keep moving. The regions still shifting late are exactly
the ones the allocation decided were worth spending on.

## Encoding rules used across all of them

- **Sequential ramp, one hue** for probability. A rainbow invents boundaries the
  numbers do not have.
- **Diverging, two hues, neutral midpoint** for signed differences only.
- **Tile or dot size = sample count**, so thin data looks thin. Adaptive n
  otherwise lies to the eye.
- **No second encoding for how a run failed.** A generation that used the whole
  context without answering counts as incorrect, exactly like a wrong digit —
  the grid measures one thing. The four-way outcome stays on every record and on
  hover.
- **Grey means no data**, never a low score.
- Both themes styled through the same custom properties; the viewer's toggle
  wins over the OS preference.
